How to install on Android

  1. Tap Download for Android above. The file is called GO-GO-Ride.apk.
  2. Open the downloaded file (from the notification or your Downloads folder).
  3. If Android asks, allow Install unknown apps for your browser, then go back.
  4. Tap Install, then Open. Allow notifications so your bus alarms can ring.
